# Portfolio — Santiago Miranda

## English

This project is a personal portfolio website built to showcase my professional profile as a Senior QA Analyst focused on API testing, accessibility, and software quality.

It is designed to present my experience, work style, and testing judgment in a clean, modern single-page format for recruiters, hiring managers, and collaborators.

### What this project does

- showcases QA experience in functional, API, and accessibility testing
- presents a clear professional narrative around risk-based testing and product quality
- highlights real project context and evidence-driven work samples
- communicates how I work, prioritize, and deliver value in cross-functional teams

### Intended use

This portfolio is intended as a digital professional profile for:

- recruiting and hiring conversations
- showcasing technical and quality-focused work to product teams
- demonstrating how I approach QA, validation, and defect reporting
- presenting a polished personal brand with a strong emphasis on quality and accessibility

### Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- Git & GitHub

### Project structure

```text
.
├── index.html
├── assets/
│   ├── avatar.jpg
│   └── ...
├── README.md
├── CLAUDE.md
└── .gitignore
```

### Run locally

Open `index.html` directly in the browser, or serve the project locally:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

### Deployment

This project is ready to be published on:

- GitHub Pages
- Netlify
- Vercel
- any static hosting service

### AI-assisted development

This portfolio was iterated with the help of AI tools to speed up content creation, structure, and visual refinement while keeping the focus on clarity, professionalism, and quality-driven storytelling.

### Objective

The goal is to show not only my experience, but also the way I work: risk prioritization, evidence-based validation, automation with judgment, and strong accessibility awareness.
