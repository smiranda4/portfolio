# Portfolio Personal — Santiago Miranda

Portfolio profesional para presentar mi perfil como Senior QA Analyst, con foco en API Testing, calidad de software, automatización inteligente y accesibilidad web.

Este proyecto funciona como una tarjeta de presentación digital para mostrar mi experiencia, forma de trabajo y enfoque profesional, sin depender de un CV tradicional.

## ✨ ¿Qué muestra este proyecto?

- experiencia en QA funcional, API y accesibilidad
- criterio de priorización por riesgo y cobertura
- capacidad para comunicar evidencia y defectos con calidad
- proyectos destacados y trabajo realista en contexto profesional
- enfoque práctico, analítico y orientado a la mejora continua

## 🧠 Enfoque de trabajo

No es solo un sitio personal: es una demostración de cómo trabajo como QA:

- validación basada en riesgo
- pruebas centradas en user impact y negocio
- evidencia clara y reproducible
- automatización con criterio, no por automatizar por automatizar
- pensamiento crítico + uso de IA como herramienta de productividad

## ▶️ Ejecutarlo localmente

Puedes abrir directamente `index.html` en el navegador o levantar un servidor local:

```bash
python -m http.server 8000
```

Luego accedé a:

```text
http://localhost:8000
```
